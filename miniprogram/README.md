# 视频保存（VideoSaver）使用说明

把抖音分享链接里的视频保存到手机相册。

## 如何使用

1. 在抖音 App 中打开想保存的视频，点击 **分享 → 复制链接**。
2. 打开本小程序，点击 **粘贴剪贴板**（或手动粘贴文案）。
3. 点击 **开始提取**，等待视频提取完成（会显示时长与文件大小）。
4. 点击 **保存视频**：当日首次保存需观看一小段广告，**之后 24 小时内保存不再提示**。
5. 保存成功后，在手机系统相册中查看；小程序底部「历史」页可回看保存记录。

## 支持的内容

- 抖音分享文案（含 `https://v.douyin.com/…` 短链）
- 抖音视频链接（含作品 ID 的完整链接）
- `.mp4 / .mov / .m4v` 等视频直链（可直接下载）

## 常见问题

**提示「该作品不存在、已删除或设为私密」**
作品已被作者删除，或作者设置了观看权限，无法保存。

**提示「当前请求较多，请稍后再试」**
同一时间请求的人较多，稍等一两分钟后重试即可。

**提示「网络异常」**
检查手机网络后重试；如果持续失败，稍后再试。

**保存的视频在哪里？**
在手机「系统相册」里；小程序内的「历史」页只保存标题、封面等记录，方便再次保存。

## 隐私说明

- 不需要登录任何账号，不收集账号信息。
- 历史记录仅保存在你自己的手机上。
